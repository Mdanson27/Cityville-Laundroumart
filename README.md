# CityVille Laundromat Smart Digital Profile

Premium, mobile-first digital profile for CityVille Laundromat.

## Required logo file

The site expects the official CityVille logo at the repository root with this exact filename:

`cityville-logo.png`

The loader and hero already reference that filename. A CSS brand fallback is shown if the image is ever unavailable.

## Features

- Cinematic water-drop loader
- Responsive mobile/desktop layout
- Call and WhatsApp quick actions
- Downloadable vCard / Save Contact
- Dynamic QR code for the deployed profile URL
- Native Share Profile action
- Price guide from the supplied CityVille artwork
- Kitintale branch location
- Embedded Google Map and direct Get Directions link
- Instagram, TikTok and official website links
- Mobile floating quick-action dock

## Deployment

This is a static site: `index.html`, `styles.css`, and `script.js`.

It can be deployed directly on GitHub Pages, Netlify, Cloudflare Pages or any static host. No build command is required.
